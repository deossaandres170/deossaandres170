**Planteamiento de proyecto** desarrollado como parte de mi formación en Análisis y Desarrollo de Software.

Ludéxico IA es una propuesta de plataforma web orientada al fortalecimiento del léxico regional mediante dinámicas de asociación de palabras, gamificación y contextos culturales.

El proyecto se encuentra en una etapa de **planteamiento y desarrollo conceptual**, donde se han trabajado aspectos como:

- Análisis de requisitos
- Historias de usuario
- Casos de uso
- Diseño de la solución
- Experiencia de usuario
- Gamificación
- Bases de datos
- Arquitectura de software
- Conceptualización de funcionalidades

> Este proyecto representa una propuesta de solución y forma parte de mi proceso de aprendizaje en desarrollo de software.
